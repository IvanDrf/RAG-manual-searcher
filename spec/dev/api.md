# Разработка API

Необходимые методы backend API 

## Авторизация

### Регистрация 

- **Метод**: `POST`

- **URL**:  `/api/v1/auth/register`

### Логин

- **Метод**: `POST`

- **URL**:  `/api/v1/auth/login`

### Выйти из аккаунта

- **Метод**: `POST`

- **URL**:  `/api/v1/auth/logout`


### Обновление access токена

- **Метод**: `POST`

- **URL**:  `/api/v1/auth/refresh`


### Получение информации о пользователе

- **Метод**: `GET`

- **URL**:  `/api/v1/auth/me`


### Подумать

Пользователю поменяли роль, но он все равно может выполнять действия со старой ролью только если не выйдет из аккаунта.
