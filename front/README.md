# MathContext · React

Русскоязычный интерфейс для чата, библиотеки математических лекций и панели администратора.

## Локальный запуск

1. Запустите backend из текущей ветки. Используйте инструкции его README, включая настройку `.env`, PostgreSQL, Redis и миграций. Установите зависимости командой `uv sync --locked` из `back/`. При первом распознавании InsightFace загружает модель `buffalo_s`, если её ещё нет в локальном кэше.
2. Из папки `front/` установите зависимости и запустите Vite.

```bash
cd front
npm ci
npm run dev
```

Откройте URL, который напечатает Vite. По умолчанию запросы `/api/v1`
проксируются в `http://127.0.0.1:8080`. Для другого адреса создайте
`front/.env.local` и перезапустите Vite.

```dotenv
AUTH_API_TARGET=http://127.0.0.1:8080
```

Для dev-режима открывайте frontend через loopback-адрес. При развёртывании
обслуживайте frontend через HTTPS и проксируйте `/api/v1` на том же
origin, чтобы браузер мог отправлять защищённые cookies сессии.

## Сценарии

- Войти существующим аккаунтом или зарегистрировать обычного пользователя. Роль приходит от API. Для панели администратора нужен аккаунт с серверной ролью `admin`.
- Создать чат или выбрать переписку в боковой панели. В демо сообщения хранятся в этом браузере отдельно для каждого аккаунта.
- Отправить одно фото до 10 МБ отдельно или вместе с текстом. Сервер распознаёт преподавателя, а чат печатает имя или сообщает, что распознать преподавателя не удалось. Фото и ответ сохраняются в локальной истории браузера.
- Открыть каталог, выбрать предмет и PDF, выделить текст на странице и нажать **«Обсудить в чате»**. Страницы без текстового слоя доступны для чтения.
- Под администратором открыть сводку расхода токенов. График и таблица используют демонстрационные данные.

Чат даёт демонстрационные ответы на сообщения без фото.

Команда `npm run build` проверяет TypeScript и собирает приложение с библиотекой PDF в `front/dist/`.
